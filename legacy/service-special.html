Comment jouer

Le téléphone circule une première fois : chacun maintient le doigt sur la carte pour découvrir son nom secret, puis la referme avant de passer l'appareil.

La majorité des joueurs, les civils, partagent le même nom. Les undercover en reçoivent un autre, proche mais différent, sans savoir qu'ils sont les intrus. Mr White, lui, ne reçoit rien du tout.

Dans l'ordre de parole affiché, chacun prononce un seul mot décrivant ce qu'il a reçu. Trop précis, il aide les intrus ; trop vague, il devient suspect. Après un tour de table, le groupe débat puis élimine un joueur, dont le rôle est révélé aussitôt.

Les civils l'emportent quand tous les intrus ont été démasqués. Les intrus l'emportent quand ils atteignent le seuil fixé dans les règles ci-dessus.
