                Comment jouer

                La majorité des joueurs, les civils, partagent le même mot. Les undercover en reçoivent un autre, proche mais différent, sans savoir qu'ils sont les intrus. Mr White, lui, ne reçoit rien du tout.

                Dans l'ordre de parole affiché, chacun donne un mot ou une courte phrase décrivant ce qu'il a reçu. Trop précis, il aide les intrus ; trop vague, il devient suspect.

                Après le tour de table, chacun vote pour éliminer un suspect. En cas d'égalité, un second vote départage les ex æquo ; s'il reste une égalité, personne n'est éliminé. Le rôle de l'éliminé est révélé. Si c'est Mr White, il tente de deviner le mot des civils : s'il réussit, les intrus gagnent aussitôt.

                Les civils l'emportent quand tous les intrus ont été démasqués. Les intrus l'emportent quand ils atteignent le nombre de civils encore en jeu.
